📁 Technical Architecture & File Structure

This module uses a clean, modular three-file architecture optimized for GitHub Pages:

huokaingthara_football_club_home_contact/
├── index.html     # Main Contact & Home page markup with bilingual support
├── style.css      # Modern dark cyberpunk/athletic theme (#0f172a slate, #00f2fe cyan)
├── script.js      # Dynamic language switcher and interactive form validation handler
└── README.md      # Comprehensive repository documentation


Key Highlights:

Instant Bilingual Toggle: Seamless switching between English (.en-text) and Khmer (.kh-text) via the navigation button.

Modern Cyberpunk Theme: High-contrast athletic dark styling optimized for desktop, tablet, and mobile screens.
